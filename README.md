# Smart Job Portal with AI Resume Analyzer

An AI-powered job portal that connects job seekers with recruiters and helps candidates analyze their resumes using Artificial Intelligence.

## Features

- User registration and login
- Separate Job Seeker and Recruiter dashboards
- Job posting and job searching
- Resume upload (PDF)
- AI-based resume analysis
- Resume and job description matching
- Job recommendations
- Application tracking
- Admin dashboard

## Tech Stack

| Component | Technology |
|---|---|
| Frontend | React.js, Tailwind CSS |
| Backend | Node.js, Express.js |
| Database | MongoDB |
| AI/ML | Python, FastAPI, NLP |
| Version Control | Git and GitHub |
| Deployment | Vercel and Render |
